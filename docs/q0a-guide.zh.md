# Q0a 实测指引：只监听，不回复

**目的：** 确认机器人实际能收到哪些消息。这一步不接模型，不会产生模型费用，程序里也没有发送代码。

**它测不出封号概率。** 通过只说明功能可用，不说明安全。

**捕获内容：** 只记事件类型、字段结构、消息长度和 ID 的散列值，不存正文、昵称和原始 ID。文件在 `captures\`，已被 git 忽略。

## 从 README 第 5 步过来

这份指引是项目开始时的实测写的，有几处和 README 不一样。你的 `.env`、`config.json` 和 Gateway 都已经有了，所以：

1. **先停 Gateway：** `.\scripts\stop.ps1`。监听工具用同一个 AppID 再开一条连接，不会检查 Gateway 在不在。mock 上两条连接都连得上，真实 QQ 上会怎样（两边都收到、只有一边收到、还是踢掉一边）没有测过，所以不要同时跑。
2. **不要再复制 `.env.example`：** 覆盖会清掉已经填好的内容，而且不提示。下面第一节只看第 3、4 条。
3. **一个小测试群就够。** 第二节的两个群，是当时为了比较机器人 QQ 的不同身份。
4. **开关保持 README 第 4 步的状态，两个都开着。** 第二节的“先不要开主动发言”和第四节的“先在开关关闭时”都是当时分开测用的，可以跳过。
5. **听完再启动回来：** `Ctrl+C` 之后 `.\scripts\start.ps1`，等 `status` 显示“连接：已连接”。`stop` 算宿主的一次非正常退出，不要反复来回，原因见 README“排错”里的崩溃保护。

## 一、准备

1. 用**单独的实名 QQ 号**登录 [q.qq.com](https://q.qq.com)，手动创建机器人。
   - 控制台若询问模型，请如实填写。
   - 控制台若要求提交个人认证材料，**先停下想清楚**，这一项要由你决定。决定提交的话，如实填写。
   - IP 白名单留空；如果被强制填写，**先停下**，核对平台要求后再继续。
2. 复制 `.env.example` 为 `.env`，在本机填入 `CLO_QQ_APP_ID` 和 `CLO_QQ_APP_SECRET`。**不要贴到聊天里。** `CLO_CHAT_API_KEY` 这一步留空。
3. 手机 QQ 升到最新版。
4. 准备好第二个账号，用来发样例。

## 二、两个测试群

都用临时小群，不要用真实的群。

| 群 | 机器人 QQ 的身份 | 谁开开关 | 测什么 |
|---|---|---|---|
| ① 基线 | 群主 | 机器人 QQ 自己，添加机器人时设置 | 文档最明确的情形 |
| ② 模拟真实情况 | 管理员 | 另一账号（群主），机器人加入后在资料页设置 | 文档没写明角色的路径 |

需要开启的开关：**获取群内全部消息**。这一步先**不要**开“主动发言”，后面 Q0b 才测。

## 三、运行

```powershell
pwsh -NoProfile -File scripts\q0-listen.ps1
```

看到 `Connected` 后，按下面的顺序发样例，发完按 `Ctrl+C`。

## 四、样例清单

每个群都做一遍，内容随便写，**不要包含真实隐私**。

**先在开关关闭时：**
1. 第二个账号 @机器人 发一句文字。
2. 第二个账号发一句不带 @ 的文字。

**打开开关后：**
3. 第二个账号 @机器人 发一句文字。
4. 第二个账号发一句不带 @ 的文字。
5. @所有人（如果权限允许）。
6. @另一个普通群友（不是机器人）。
7. 只在文字里打“可洛”，不 @。
8. 带一个网址的文字。
9. 引用机器人的消息回复（如果有的话；Q0a 机器人不发言，可跳过）。
10. @机器人 并附一张图片。
11. 只发一张图片。
12. 群主或管理员发一句（确认不同身份）。

**私聊：**
13. 从已列入开发体验用户的账号私聊机器人。开发体验用户是管理端“开发设置”里的名单，见 README 第 4 步。可洛不回私聊，所以第 13 到 15 条只是看平台的行为，可以跳过。
14. 从**未列入**的账号私聊机器人（可能根本发不出去，这也是结果）。

**群内未列入的成员：**
15. 让未列入开发体验用户的账号在群里 @机器人。

如果某一步做不到，记下来，这本身就是有用的结果。

## 五、什么时候立刻停

- 机器人加不进群。
- 程序报告 `Gateway closed with code 4914` 或 `4915`。
- 平台发来任何警告或通知。
- 开关打开后仍然收不到不带 @ 的消息。**不要急着提交认证材料**，先核对平台要求。

## 六、做完之后

记下每个群开关设置的实际情况（哪一步能操作、哪一步看不到选项）。捕获文件在本机 `captures` 目录，不要贴到公开的地方。确认你的群能收到需要的消息后，进入 live 时用 `clo ack q0` 记录这一步，见 README。
